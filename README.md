# Pays du jour

One country a day: a ~10-minute read per country, covering map, climate, way of life,
wealth and inequality, resources, seasons and temperatures, main cities, political
regime, recent leaders and current political dynamics.

## Layout
- `fiches/` : one file per country (`<iso3>-<slug>.md`)
- `assets/cartes/` : maps and images
- `data/` : country list, reading order, sources
- `templates/fiche.md` : section template every fiche follows
